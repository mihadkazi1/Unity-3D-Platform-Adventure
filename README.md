# 🎮 Unity 3D Platform Adventure

A 3D platform-based adventure game developed using **Unity and C#**.

The player explores a fantasy-style environment, collects coins, unlocks a key, avoids hazards, and reaches the door to complete the level.

---

## 🕹️ Gameplay

The main gameplay progression is:

**Start Game → Collect Coins → Key Appears → Collect Key → Reach Door → Victory → Next Level**

The player must collect all required coins before the key becomes available.
